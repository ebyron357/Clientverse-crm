# Project Overview

ClientVerse CRM is an AI-native client operations platform spanning the client lifecycle: **WIN → ONBOARD → SERVE → RETAIN → EXPAND**.

Core areas documented in the repository include client workspaces, pipeline, commitments, deliverables, approvals, explainable health, governed MCP tools, webhooks, integrations, audit history, and outcome tracking.

Primary stack documented by the repository:
- FastAPI backend
- MongoDB
- React frontend
- Tailwind / shadcn UI
- governed MCP and webhook layers
- external provider integrations including Google and Stripe

The project should be documented as an operating system for client delivery, not merely a contact database.
