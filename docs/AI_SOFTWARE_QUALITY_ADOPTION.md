# AI Software Quality & Security — Repository Adoption

This repository adopts the proposed canonical standard in [AI-Operating-Standards PR #8](https://github.com/ebyron357/AI-Operating-Standards/pull/8).

## Required process
- Inventory actual repository architecture, live deployment, roles, data, integrations, and AI agents before claiming findings.
- Audit visual consistency, code debris, fake UI, responsive behavior, accessibility, security, data integrity, integrations, agent permissions, performance, privacy/compliance, tests, deployment, and documentation.
- Log each finding with severity P0-P3, evidence, affected file/line, reproduction, repair, owner, tests, and status.
- Preserve working functionality and existing project data. No invented blockers or passing tests.
- Use isolated branches and reviewable PRs. Owner retains final production-release authority.
- HIPAA, NIST, CMMC, and FedRAMP claims require scope-specific evidence and applicable assessments.

## Rollout status
- [ ] Baseline inventoried
- [ ] Audit performed with evidence
- [ ] P0/P1 findings addressed
- [ ] Automated and manual tests passed
- [ ] Owner approved release
